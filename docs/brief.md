## 1. 출발점: 클리앙 "PALAZZO"(magii30)의 유증 매매법 (2020년 10월 글 3편)

### 1-1. 그가 주장한 방법
1. 주주배정 유상증자 공시 종목을 3~6개월 공부
2. **신주배정기준일 전(권리락 전)** 최대한 저가 매수 → 보유주 × 배정비율만큼 신주인수권 확보
3. 선택: 청약(+초과청약) 또는 신주인수권증서 매도 (HTS 표기: `종목명 + 숫자 + R`, 예: "SK디앤디 12R")
4. 신주 입고일 09:10경 정리 → 며칠 매물 소화 후 재매수 (추세 좋으면 보유)
5. 자금 회전: 기준일이 다른 두 종목을 매수 → 먼저 권리 확보한 종목은 권리락일에 매도 → 그 돈을 다음 종목에 투입해 권리 수량 2배

### 1-2. 그의 종목 필터 5개 (전부 충족)
1. 업계 1~3위 / 2. 절대 안 망할 회사(지금은 힘들어도 성장성) / 3. 대체 불가 사업 / 4. 직전 분기 영업흑자 + 다음 분기 흑자 예상 / 5. 주가가 52주 고저 범위의 중간 이하

### 1-3. 그가 댓글로 그린 주가 사이클
유증 전 상승 → 권리락 조정 → 기준일 후 청약 전까지 서서히 하락(인수권 매도 압력) → 청약 후 반등 → 신주 입고일 매물로 하락 → 약 1달 뒤 회복

### 1-4. 철학
손실 없는 자리에서 / 목표는 낮게 / 천천히 우상향 / 초등학생에게 10분 설명 가능해야 매수 / 확신 시 비중 크게

## 2. 검증 결과: 팔라조 논리의 오류 (확정된 결론)

### 2-1. "20~30% 할인 = 20~30% 수익"은 틀림 — 권리락 때문에 이론상 제로섬
- 발행가 산식: `발행가 = 기준주가 × (1 − 할인율) / (1 + 증자비율 × 할인율)`
- 이를 풀면 **발행가 = 권리락 이론가 × (1 − 할인율)** → 할인은 이미 떨어진 가격 기준.
- 권리락 이론가: `P_x = (P + r × I) / (1 + r)` (P: 권리락 전 주가, r: 배정비율, I: 발행가)
- 예시: P=10,000, r=0.4, 할인율 25% → I=6,818, P_x=9,091
  - 기존주 손실 −909 / 신주 이득 0.4 × 2,273 = +909 → **합계 0**
- 인수권을 팔아 번 돈도 "수익"이 아니라 권리락으로 깎인 보유주 가치의 보상.

### 2-2. 기타 오류
- 그의 1번 종목은 42,000→35,000으로 실제 할인율 16.7% (30% 아님).
- 초과청약은 **배정주식수의 20%** 한도이고, 실권주가 생겨야만 배정됨. "0.4 + 0.2" 식의 합산은 틀림.
- "손실 불가"는 2020년 유동성 장세 + 대한항공 회복 덕분의 **생존편향**.

### 2-3. 실제 수익원 (진짜 엣지 후보)
1. **방향성 베팅**: 필터 5개 = "유증 악재로 눌린 우량주 줍기". 이벤트가 아니라 회복이 수익원.
2. **수급 사이클 타이밍**: 인수권 기간 매도 압력, 신주 상장일 매물.
3. **인수권 괴리**: 인수권 가격 ≠ (주가 − 발행가). 비싸면 인수권 매도, 싸면 본주 대신 인수권 매수.
4. **레버리지 특성**: 권리락 전 보유자는 인수권이 옵션처럼 작동 → 권리락 후 주가 변동이 확대 반영됨(양방향).

### 2-4. 인수권 괴리가 방치되는 이유
- 청약 대금 없는 주주의 강제 투매 (5거래일 안에 안 팔면 권리 소멸)
- 신주 상장일 물량 폭탄에 대한 선반영
- **유증 공시 후 공매도한 자는 해당 유증 참여 금지** → "인수권 매수 + 본주 공매도" 차익거래가 막힘

### 2-5. 두 전략의 결합 구조 (사용자 합의)
- B(눌린 우량주 줍기)가 본업, A(인수권 괴리 차익)가 보너스.
- B로 진입 → 인수권 거래기간에 매일 괴리 체크 → 비싸면 인수권 매도(A 발동), 아니면 청약해 B 지속 → 신주 상장일 매물 구간에서 추가 기회 탐색.

## 5. 자동화 파이프라인 설계

1. **감지**: DART OpenAPI 주요사항보고서 중 "유상증자 결정" API를 매일 폴링 → 증자방식이 주주배정 계열인 것만 필터
   - 공시에 자금 목적별 금액·증자방식·발행주식수 등이 필드로 제공되는 것으로 파악됨 → **정확한 엔드포인트·필드명은 검증 필요**
2. **일정 파싱**: 증권신고서/정정공시에서 기준일·권리락일·인수권 상장기간·발행가 확정일·청약일·상장일 추출 (정정 공시로 일정 변경 잦음 → 정정 추적 필수)
3. **점수화**: 4장의 필터 변수로 자동 채점 (A등급: 성장형 / C등급: 채무상환·초대형 희석)
4. **알림** (텔레그램 또는 카톡, 헤더 규칙 준수)
   - 신규 유증 감지 + 등급
   - 권리락 D-1
   - 인수권 거래기간 매일 괴리율 계산 → 임계값 초과 시 알림
   - 신주 상장일 D-1, D+0, D+5
5. **기록 DB**: 모든 케이스의 공시 필드 + 일정 + 일별 본주·인수권 시세 저장 → 그대로 백테스트 데이터
   - 인수권 시세 소스: 증권사 API 또는 KRX 정보데이터시스템 (**확인 필요**)
