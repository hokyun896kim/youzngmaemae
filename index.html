📘 이 사이트를 읽는 법

유증 레이더는 "어느 유증 케이스를 깊게 팔지" 골라주는 발견 도구입니다. 매수·매도 신호를 주지 않습니다.

1단계 · 증자방식부터 거른다주주배정 계열(주주배정증자, 주주배정후 실권주 일반공모)만 신주인수권증서가 나옵니다. 나머지(제3자배정·일반공모)는 관찰 탭으로 빠집니다.
2단계 · 회사부터 본다 (B = 본업)자금 목적 막대가 채무상환 위주거나, 신주÷기존주가 100%를 넘는 초대형 희석이면 빨간 배지가 붙습니다. 필터 5개(업계 1~3위 / 안 망할 회사 / 대체 불가 / 영업흑자 / 52주 중간 이하)를 통과해야 B 후보입니다.
3단계 · 사이클 위치를 본다카드의 금색 라벨이 지금 구간입니다: ① 권리 확보 → ② 권리락 후 → ③ 인수권 거래 중 → ④ 청약 → ⑤ 상장 대기 → ⑥ 상장 후 매물 소화. 타임라인의 빨간 선이 오늘입니다.
4단계 · 인수권 괴리를 본다 (A = 보너스)괴리율 = 인수권 ÷ (본주 − 발행가) − 1.
음수(초록) = 인수권이 싸다 → "인수권 매수 + 청약"으로 본주보다 싸게 신주 확보 검토.
양수(빨강) = 인수권이 비싸다 → 보유 인수권 매도 검토.
예) SK디앤디 12R: 인수권 636 / 이론가 1,135(3,395 − 2,260) → −44%, 인수권+청약 원가 2,896원.

⚖️ 이미 결론 난 것 (재논의 금지)

할인율은 수익이 아닙니다. 권리락 이론가 P_x = (P + r·I) / (1 + r)로 이론상 제로섬이고, 인수권 매도 대금은 깎인 보유주 가치의 보상입니다. 초과청약은 배정주식의 20% 한도이고 실권주가 있어야만 배정됩니다. 진짜 엣지는 회복(B)·수급 타이밍·인수권 괴리(A)·레버리지입니다.

🤖 GPT 분석지침 — 프롬프트 두 종류

전체 브리핑 프롬프트 (상단 금색 버튼)진행 중인 모든 케이스와 오늘의 인수권 전체를 한 번에 넘깁니다. GPT가 우선순위 분류(B/A/관찰/제외), 괴리 랭킹 TOP3, 5거래일 캘린더, 가설(H1~H3) 샘플, 위험 신호를 정리합니다. 매일 아침 한 번 쓰는 용도입니다.
개별기업 분석 프롬프트 (각 카드 하단)한 케이스의 공시·일정·정정 이력·괴리율 추이와 1차 자료 링크를 채워 넘깁니다. 자금 목적의 실체 → 필터 5개 판정 → 발행가 산식·보험 구간 → 최대주주 청약 → A 판정 → 수급 사이클 → 베어 케이스 → 반증 조건 → 결론 순서로 깊게 분석합니다.

두 프롬프트 모두 위 결론을 전제로, 이 수집기의 맹점(파서 미검증·권리락일 추정·발행가 산식 미확인)을 검증 지침으로 담고 있습니다. 1차 자료(DART 원문·증권신고서)를 같이 읽힐수록 품질이 올라갑니다.

⛔ 이 도구가 하지 않는 것

매수·매도 신호, 목표가는 주지 않습니다. MACD·볼린저는 쓰지 않습니다(타이밍은 일목·RSI 50 게이트·ATR로만). 최종 판단은 1차 자료와 미래에셋 화면으로 직접 확인한 뒤 형님이 내립니다.

데이터: OpenDART(유상증자결정·증권신고서·원문), KRX Open API(sr_bydd_trd·stk/ksq_bydd_trd). 권리락일은 기준일 전 1영업일 추정치. 일정 파서는 실제 공시로 검증 전이므로 원문 링크로 반드시 교차확인. 매매 판단은 미래에셋 화면으로 눈검증.
